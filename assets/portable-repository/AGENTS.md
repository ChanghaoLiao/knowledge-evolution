# Portable Personal Knowledge Repository

This repository is a private personal-knowledge environment generated by the public Knowledge Evolution Skill.

## Operating rules

- Use `.agents/skills/knowledge-evolution/SKILL.md` as the generic governance engine.
- Keep personal knowledge and configuration outside the vendored Skill snapshot.
- Treat `Knowledge/` as the governed knowledge root unless shared configuration says otherwise.
- Read `.knowledge-evolution/portability.yaml` before Git synchronization.
- Read `.local/device.yaml` only for this device's logical-source path mappings. Never commit it.
- Synchronize once before generating a proposal; use fast-forward-only behavior and stop when dirty paths overlap incoming changes.
- Create a knowledge proposal before editing `Knowledge/`; apply only approved Change IDs.
- Do not fetch or pull during Apply. If a later push is rejected, preserve the local commit and stop without rebasing or merging.
- Commit and push only explicitly approved paths. Never force-push or auto-resolve conflicts.
- Never add credentials, tokens, private keys, raw Import extraction text, or Obsidian workspace state.
- Treat a source missing from this device as unavailable, not deleted.

## New device

After cloning, create `.local/device.yaml` from `.local/device.yaml.example`, fill only local path mappings, and run a read-only Audit before the first Apply. Global Skill installation is optional and requires a separate user action.
