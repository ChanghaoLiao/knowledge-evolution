# {{REPOSITORY_NAME}}

Private portable knowledge environment generated by [Knowledge Evolution](https://github.com/ChanghaoLiao/knowledge-evolution).

## What is here

- `Knowledge/`: governed Markdown knowledge and shared profile.
- `.agents/skills/knowledge-evolution/`: generic repository-scoped Skill snapshot.
- `.knowledge-evolution/portability.yaml`: shared Git and privacy policy.
- `.local/device.yaml.example`: schema for local source-path mappings.
- `AGENTS.md`: repository operating boundaries.

Personal configuration remains outside the vendored Skill, so a reviewed Skill update does not overwrite the user's knowledge or profile.

## First use on this device

1. Open this repository in Codex.
2. Copy `.local/device.yaml.example` to `.local/device.yaml` and replace placeholders with paths for this device.
3. Ask `$knowledge-evolution` for a read-only status or Audit.
4. If the Skill must be available outside this repository, run its installer explicitly:

```bash
python3 .agents/skills/knowledge-evolution/scripts/install_portable_skill.py \
  --repository-root .
```

Git clone never runs installers automatically.

## Pre-proposal synchronization

Run this once before reading canonical knowledge to generate a proposal. Do not run it again during Apply.

```bash
python3 .agents/skills/knowledge-evolution/scripts/sync_knowledge_repository.py status --repo . --pretty
python3 .agents/skills/knowledge-evolution/scripts/sync_knowledge_repository.py pull --repo . --pretty
```

After an approved knowledge Apply, publish only approved paths:

```bash
python3 .agents/skills/knowledge-evolution/scripts/sync_knowledge_repository.py publish \
  --repo . \
  --path Knowledge \
  --message "knowledge: apply approved proposal" \
  --push \
  --pretty
```

The sync tool preserves non-overlapping dirty paths, refuses overlaps, divergence, unrelated staged changes, public GitHub remotes, and force-pushes. If a normal push is rejected after Apply, it keeps the local approved commit and does not pull, rebase, or merge.
